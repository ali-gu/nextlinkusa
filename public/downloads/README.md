# Downloads

Drop the product catalogue PDF here, then point `NEXT_PUBLIC_CATALOG_URL` at it
(for example `/downloads/nextlink-usa-product-catalog.pdf`).

Until that variable is set, every "Download Product Catalog" button on the site
reads "Request the Product Catalog" and opens a pre-addressed email instead of
linking to a file that does not exist.

Files in this directory are served with a 24-hour cache header.
